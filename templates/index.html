Project Info
About This Project

Summary

SupplyGuard deploys a two-stage machine learning system optimized over gradient boosted ensembles. Stage 1 executes an XGBoost Classifier targeted at a strict 45.0% decision threshold to secure elevated operational recall. Stage 2 triggers an isolated XGBoost Severity Regressor to compute down-stream downtime consequences without injecting data leaks into the classifier loop.
